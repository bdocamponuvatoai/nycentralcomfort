## 4. After generating

1. Download each image as PNG and save it as `assets-src/<name>.original.png`
   (for example `assets-src/h1-desktop.original.png`).
2. Review it: warm and bright (not dark), no readable text, logos or brand names on equipment or
   shirts, faces anonymous, exactly one orange element, equipment installed correctly. Retouch if
   needed and save as `assets-src/<name>.png`.
3. Run `npm run media -- photo <name>`, then paste the printed width, height and blur placeholder
   into `content/assets.ts` and write alt text that describes the new shot.
4. Check the frame on the page matches the photo's aspect ratio, so nothing is cropped.
5. For the Gallery / Completed Projects page, use the **real** project photos and videos from the
   current site. Do not replace them with generated images. Pick the cleanest shots, crop out
   trash and boxes, and colour-grade slightly warmer. Avoid the darkest mechanical-room shots or use
   them small. Brand logos on real equipment are fine in real project photos.

**If ChatGPT drifts dark, gritty or posed**, reply: "Brighter, warmer, cleaner: soft golden
sun, ivory walls, fewer objects, more empty space, nobody looking at camera, Apple-level calm."

## 6. Design overrides for this client (paste after the brief)

The Blueprint defaults to a matte-black site with one solid colour-block section. This client wants
the opposite: **warm, light, Apple-level calm**, in their own brand colours. Apply these overrides
on top of Parts 2–7:

```

   Section rhythm alternates warm ivory (#FAF7F2) → white (#FFFFFF) → soft stone (#F1EBE3).
   Separate sections with whitespace and hairlines, not colour slabs.

2. Tokens from the brand (current site: orange #FF800F, navy #001064). Verify contrast:
   bg #FAF7F2 · surface #FFFFFF · surface-2 #F1EBE3 · fg/ink #0B1638 (deep brand navy, never black)
   muted #5A6178 · line rgb(11 22 56 / 0.10) · accent (text on light) #B35300

   - Huge whitespace; section padding 128–176px desktop, 80–96px mobile. Max text width ~680px.
   - Typography: one refined grotesk for everything (e.g. Inter Tight or Manrope via next/font),
```
